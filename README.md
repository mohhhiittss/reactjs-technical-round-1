# ReactJS Task Management Dashboard

A responsive Task Management Dashboard built for the ReactJS Technical Round 1 practical assignment.

## Features

- Create tasks
- View all tasks
- Edit tasks
- Delete tasks with confirmation
- Change task status
- Search by title and description
- Filter by status
- Filter by priority
- Combined search and filters
- Dynamic task statistics
- Form validation
- Responsive UI
- LocalStorage persistence

## Technologies

- ReactJS
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Demonstrated

- Functional Components
- Props
- State
- useState
- useEffect
- Event Handling
- Conditional Rendering
- List Rendering
- Forms
- Reusable Components

## Run Locally

```bash
git clone <repository-url>
cd reactjs-technical-round-1
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```
